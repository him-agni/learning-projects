# Stripe Payment Integration

A simple e-commerce checkout flow using [Stripe Checkout](https://stripe.com/docs/payments/checkout). A static frontend sends a request to a Node.js/Express backend, which creates a Stripe Checkout session and redirects the user to Stripe's hosted payment page.

---

## Project Structure

```
Stripe payment/
├── Frontend/
│   ├── index.html       # Main page with checkout button
│   ├── script.js        # Calls backend to create checkout session
│   ├── success.html     # Shown after successful payment
│   └── cancel.html      # Shown after cancelled payment
└── server/
    ├── server.js        # Express server — checkout session + webhook
    ├── .env             # Environment variables (not committed)
    └── package.json
```

## Setup

### 1. Install server dependencies

```powershell
cd server
npm install
```

### 2. Configure environment variables

Create `server/.env` (or edit the existing one):

```env
CLIENT_URL=http://localhost:5500/Frontend
SERVER_URL=http://localhost:3000
STRIPE_PRIVATE_KEY=sk_test_your_key_here
STRIPE_WEBHOOK_SECRET=whsec_your_secret_here
```

- Get `STRIPE_PRIVATE_KEY` from your [Stripe Dashboard](https://dashboard.stripe.com/test/apikeys) under **Developers → API keys → Secret key**
- `STRIPE_WEBHOOK_SECRET` is generated by the Stripe CLI — see the Testing section below

## Running the App

You need **two terminals** running at the same time.

**Terminal 1 — Start the backend server:**

```powershell
cd server
node server.js
```

Expected output:
```
Server running on port 3000
```

> To auto-restart on file changes during development, use `npm run devStart` instead (uses nodemon).

**Terminal 2 — Serve the frontend:**

Open `Frontend/index.html` in VS Code, right-click → **Open with Live Server**.

The frontend runs at `http://localhost:5500/Frontend/index.html`.

## How It Works

1. User clicks **Checkout** on the frontend
2. `script.js` sends a `POST` request to `http://localhost:3000/create-checkout-session` with the cart items
3. The server creates a Stripe Checkout session and returns a redirect URL
4. The browser redirects to Stripe's hosted checkout page
5. After payment, Stripe redirects to `success.html` or `cancel.html`
6. Stripe also sends a webhook event to `/webhook` — the server verifies it and logs the order details

### Testing Webhooks (with Stripe CLI)

Webhooks let your server react to payment events (e.g., save an order to a database).

**Step 1 — Install the Stripe CLI**

Download from [https://github.com/stripe/stripe-cli/releases/latest](https://github.com/stripe/stripe-cli/releases/latest), extract `stripe.exe`, and place it in `C:\stripe\`.

Add to PATH (run once, then restart terminal):
```powershell
[System.Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\stripe", "User")
```

Or for the current session only:
```powershell
$env:Path = $env:Path + ";C:\stripe"
```

**Step 2 — Login to Stripe CLI**

```powershell
stripe login
```

A browser window opens — authorize with your Stripe account.

**Step 3 — Start the webhook listener**

```powershell
stripe listen --forward-to localhost:3000/webhook
```

Copy the `whsec_...` secret printed in the terminal and paste it into `server/.env` as `STRIPE_WEBHOOK_SECRET`. Restart the server.

**Step 4 — Do a test payment**

Complete a checkout using the test card. After payment you should see:

In the `stripe listen` terminal:
```
[200] POST http://localhost:3000/webhook [checkout.session.completed]
```

In the `node server.js` terminal:
```
Payment successful!
  Session ID: cs_test_...
  Amount paid: 500 USD
  Customer email: test@example.com
```

If you see both — your webhook is working.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/create-checkout-session` | Creates a Stripe Checkout session, returns `{ url }` |
| `POST` | `/webhook` | Receives Stripe webhook events |

## Going to Production

1. Replace the test keys (`sk_test_...`) with live keys (`sk_live_...`) from the Stripe Dashboard
2. Set up a real webhook endpoint in **Stripe Dashboard → Developers → Webhooks** pointing to your deployed server URL
3. Replace `STRIPE_WEBHOOK_SECRET` with the secret from the dashboard (not the CLI)
4. Update `CLIENT_URL` and `SERVER_URL` to your production URLs
